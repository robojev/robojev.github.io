RoboJev

Structured System-1 decisions for long-horizon embodied agents — reason rarely, decide often, act with skills.

Abstract

Long-horizon robot agents repeatedly ask the same closed questions — Did the grasp hold? Did the skill finish? Retry or replan? Today those questions often trigger another LLM or VLM call. RoboJev splits the stack into Reasoning, Decision, and Action: an LLM plans only when the world genuinely needs open-ended thought, a Jev-style System-1 layer returns typed judgments with confidence, and skill controllers execute. Low-confidence decisions escalate; high-confidence retries stay cheap.

Method

One symbolic kitchen task — put the apple in the fridge and close the door — is enough to exercise the loop. Perception for control is state text; rendered frames are for display only.

Layer 1

Reasoning

LLM/VLM writes or replaces a skill plan. Called at start, on replan, and on confidence-gated escalation.

Layer 2

Decision

After every skill: grasp_ok, skill_done, failure type, recovery action — parallel noul / choice answers with confidence.

Layer 3

Action

Skill controllers run pick, move, open, place, and close. No image input is required for control.
